    How a day works

    1. A reminder fires. Tap it and the timer starts on today's system design item.
    2. Watch, read or practise on the linked page. For DSA, solve on NeetCode.
    3. Come back, tap Stop and log, set the status and write one note.
    4. The day completes when both tasks pass the minimum. Complete days unlock the next level.
    5. Missed a day? Never miss twice. The minimum version still counts.
